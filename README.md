# Call Complexity Scorecard -- Portable Demo

A fully self-contained, sample-data version of the Call Complexity Scorecard
dashboard. No BigQuery, no FastAPI backend, no Walmart SSO -- everything
renders from an embedded fictional dataset.

## Just want to open it?

**`call-complexity-scorecard-demo.html`** is the whole thing in one file.
Double-click it (or drag it into a browser tab). No server needed. The only
network calls it makes are to the Tailwind and Chart.js CDNs.

## What's fake, what's real

- **Real:** the scoring formula (6 weighted KPIs, min-max normalization to
  0-100, LOW/MEDIUM/HIGH tier thresholds), all chart types, the contact
  drilldown + radar chart, KPI cards, insights, and recommendations logic.
  These are copied verbatim from the live app's `dashboard.js` -- they're
  generic, data-driven functions that don't know or care where the data
  came from.
- **Fake:** every number. `sample_contacts.js` holds ~6,700 synthetic
  contact-level records across a fictional queue/department/channel
  taxonomy, generated by `generate_sample_data.py`. Volumes are calibrated
  to roughly an 80/15/5 Low/Medium/High split (matching the *design intent*
  documented in the source repo's own SQL comments) -- not the real
  production distribution or scale.

## Source files (for editing / regenerating)

| File | Purpose |
|---|---|
| `index.html` | The dashboard shell, split version (loads the JS files below via `<script src>`) |
| `dashboard.js` | Rendering logic -- copied from the live app, with only the 3 network-fetching functions (`loadMetadata`, `refreshAll`, `_triggerContactRefresh`) replaced by local-data equivalents |
| `portable-data.js` | Client-side aggregation -- computes the same shapes `/api/metadata`, `/api/summary`, and `/hx/contacts` would, from the embedded contact array |
| `sample_contacts.js` | The embedded fictional dataset |
| `generate_sample_data.py` | Regenerates `sample_contacts.js` -- tweak the `QUEUES` table or `TIER_PROBS` to change the taxonomy or score distribution |
| `build_standalone.py` | Inlines `index.html` + the three JS files into `call-complexity-scorecard-demo.html` |

To change the sample data: edit `generate_sample_data.py`, run it, then run
`build_standalone.py` to refresh the single-file bundle.

## Confidentiality note

No real Walmart data, table names, queue names, or volumes appear anywhere
in this folder. Every name, number, and category is fictional.
